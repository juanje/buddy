## Only Buddy's own instructions

Buddy was also reading instruction files that belong to coding tools — anything that leaves an `AGENTS.md`, a `CLAUDE.md`, or a skill on disk. Those files could sit in your Buddy folder, in a folder above it, or in your home directory, and they were added to every conversation and to the background work Buddy does when you are not looking. They are ignored now. Buddy still reads the rules it keeps for itself, and it reads them once.

**What you could see**

- **Instructions from a coding assistant no longer appear in chat.** If you also use Claude Code or a similar tool, it may have left skills or an `AGENTS.md` / `CLAUDE.md` on your machine. Buddy was loading those into the conversation, so the assistant could try to follow them — including things Buddy cannot do, such as running commands. It no longer looks for them.
- **Your Buddy rules were being applied twice.** The same rules file was included by Buddy and again by the agent library underneath. It is included once now, so the conversation starts with less repeated instruction.
- **Background maintenance was reading the chat rules.** The work Buddy does on its own — daily consolidation and similar — is supposed to ignore the chat rule file, because those rules are written for a conversation with you. They were being added back anyway. They are left out again.

**What changed underneath**

Two libraries with known vulnerabilities were updated (`source-map-js` and `simple-git`). Nothing you interact with changed because of that. The test suite now fails if a future session is built in a way that turns this discovery back on.

1,479 unit tests and 594 BDD scenarios pass.
