## Cheaper, faster consolidation

Background consolidation now picks a lighter model for mechanical work.
Depths 1 and 2 — log rotation, index rebuilds, counter reconciliation —
run on the provider's fast tier with reasoning disabled. Depth 3 keeps the
configured model for judgment tasks. The split also applies to local models:
same model, but with thinking off. This reduces cost, latency, and — based
on local-model evals — improves instruction following.

**What changed underneath**

Consolidation depth 2 gained a step that reviews user-model updates:
cross-domain principle abstraction surfaces patterns the user repeats
across different areas and records them as first-class concepts.
A manual eval script (`scripts/eval-markov.ts`) measures whether the
user profile stays accurate and current; it loads questions from an external
JSON file per instance, so personal data never enters the repo.
