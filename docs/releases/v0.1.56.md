## Dashboards over your files

You can ask Buddy for a dashboard and open it in the wide viewer. It reads the files Buddy already keeps — tasks, projects, logs, the journal — and also a CSV or a markdown file you point it at. Charts are drawn by Buddy itself.

**What you could see**

- **Ask for a dashboard in chat.** Buddy writes it under `user/dashboards/` and you open it like any other file. It fills the window. A board, a list, a table, a counter, a status card, or a chart (bars, a line, progress, a calendar, a timeline) are all the same kind of file. If one widget is broken, the rest still render.
- **Tables stay readable.** A long table shows 50 rows at a time, with a control for the rows that are left. Opening a CSV on its own shows that same table.
- **A series you agree on lives apart from the dashboard.** A migraine log, a sprint record, anything with a fixed set of columns goes in `user/data/`. When that series is set to record on mention, saying you had one adds a row. You can correct a row the same way. Numbers Buddy inferred, rather than ones you stated, are marked on the widget so they do not look like a measurement.
- **Inline notes show their age.** A block Buddy wrote into the dashboard says when it was updated and what it was based on.

**What changed underneath**

Dashboards and registered data files are written only through Buddy's own tools, so an invalid file cannot arrive from a free edit in chat. Daily consolidation can be told which series still need a row, and which inline blocks are due for a refresh. Nothing there changes what you see until a consolidation run uses it.
