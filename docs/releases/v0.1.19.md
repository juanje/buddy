## Clearer routing and an OAuth race fix

Buddy now has explicit rules for where information goes when you share it. Ideas, concepts, and knowledge you want to keep go to your workspace. Tasks and reminders go to your inbox. What Buddy learns about you — preferences, patterns, how to help you better — stays in Buddy's own memory. The agent no longer needs to ask where to save things in the common cases.

**What you could see**

- **On macOS, the downloaded DMG showed "is damaged and can't be opened".** The app bundle had no code signature at all, and Gatekeeper treats unsigned-plus-quarantined downloads as non-bypassable. The release workflow now ad-hoc signs the macOS bundle, which downgrades the error to the standard "unidentified developer" warning — dismissible with right-click → Open.
- **First sign-in with OpenAI failed silently in development mode.** An internal module loaded its dependencies asynchronously but used them synchronously, so the first OAuth attempt always failed. The module is now preloaded before the setup wizard runs.

**What was one small change away from going wrong**

- **On macOS, post-consolidation filename repair could rename a file to an unexpected suffix.** If the agent created a file with uppercase letters (e.g. `MyConcept.md`), the validator tried to rename it to `myconcept.md` but the case-insensitive filesystem reported a collision with itself, so it ended up as `myconcept-2.md`. Nobody hit this because consolidation rarely produces uppercase filenames, but the first one would have landed in the wrong place.

**What changed underneath**

The routing rule is stated in the base prompt (`agents-base.md`) and in the instance template (`AGENTS.md`), so it applies to both new and existing instances after the boot refresh. The self-documentation pages (`how-memory-works.md`, `capabilities.md`) now describe three distinct spaces — your second brain, your task list, and Buddy's memory — instead of two. Spec references to developer-only local paths were replaced with in-repo cross-links. Dependency versions were updated to resolve known security advisories.
