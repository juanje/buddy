## The maintenance audit

No new features. Four passes over the codebase looking for dead code, stale comments, hardcoded values, duplicated logic and documentation that had quietly stopped matching the code. Almost everything that changed is invisible from the outside — but two things were not, and a few of the rest are worth knowing about.

**What you could see**

- **The "getting ready" notice was unreadable in light mode.** It asked for two colours that are not defined anywhere. CSS does not complain about that — it falls back to the value written beside the name, which in this case was a dark-theme grey. So the notice drew itself dark-on-dark against a light background, and had done since the day it shipped.
- **The About dialog linked to a repository that no longer exists**, left over from the rename to Buddy.

**What was one small change away from going wrong**

- **Cancelling a provider sign-in was recognised by matching the English words "Login cancelled".** Closing the browser window worked correctly today, but only by coincidence: translating the app, or the provider rewording its own message, would have turned every cancelled sign-in into an error dialog. Cancellation is now reported properly rather than guessed from text.
- **The test suite started a real background process on every run.** As things stood it exited immediately without touching anything — but the only thing preventing it from reading stored credentials and making a paid API call was a filename in a test that happens not to exist.
- **The version number lives in five files.** The previous release went out with one of them out of step. It is now written by a single command and checked automatically, so a release cannot be cut with them disagreeing.
