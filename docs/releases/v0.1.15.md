## Guards that keep your memory intact

Consolidation — the background process that organizes Buddy's memory — could
destroy file structure when running with smaller local models. This release
adds deterministic guards that catch and revert structural damage before it
persists, plus a batch of prompt and session fixes that improve reliability
across the board.

**What you could see**

- **A "thought" label leaked into assistant messages.** Some local models
  emit a bare `thought` token before their actual reply. Buddy now strips it
  before it reaches the chat bubble.

- **Log rotation wrote operational noise to the daily log.** The rotation
  entry appeared as session content, cluttering the record. It is now
  suppressed.

- **Deferred items appeared as internal notes instead of user messages.**
  The text in the banner and notifications read like an agent reminder
  rather than a direct message to the user.

**What was one small change away from going wrong**

- **Consolidation could destroy section headings and frontmatter.** A model
  rewriting a file might strip its `#` title, `##` section headings, or
  `---` frontmatter block — all structural anchors the system relies on.
  A heading-snapshot guard now captures the heading set and frontmatter
  presence before every write, and restores the file if anything
  disappeared. This fires in both chat and maintenance sessions.

- **Deep consolidation reused one session for all depths.** Context from
  earlier depths accumulated and exhausted the model's effective window,
  causing depth 3 to produce incoherent output. Each depth now runs in its
  own session.

- **The Hebbian guard was not installed on maintenance sessions.** Access
  metadata could be corrupted by the model writing `access_count` and
  `last_accessed` fields during consolidation. The guard — which already
  worked in chat — is now wired into maintenance too.

**What changed underneath**

Prompt improvements across consolidation, reflect, and the base agent
instructions: edit-batching guidance to prevent corrupt multi-edit turns,
queue-file anchoring on section headings instead of ambiguous frontmatter
delimiters, `git log` for created-date recovery instead of unreliable
content scanning, plain-language date injection in session context, reflect
now distinguishes "Tasks captured" from "Information stored", and empty
sessions skip reflect entirely. Tool result events are now logged for
observability, and `copy_file` respects session-allowed paths for
attachments.

835 unit tests and 274 scenarios. In eval runs with gemma-4 12B,
consolidation went from destroying files to producing usable results with
no data loss — 3x faster and structurally intact.
