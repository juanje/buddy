## API keys work without restarting

Adding a provider via API key — Google Gemini, or any key-based provider —
failed silently during setup and in Settings. The key was saved to disk but
the running session never picked it up. A restart was the only workaround.
This is now fixed: the key takes effect immediately.

**What you could see**

- **Gemini setup failed with "No API key found for the selected model."** The
  key was validated and stored, but the live session still had no credentials
  in memory. Both the setup wizard and Settings → Add provider were affected.
  The session now receives the key the moment it is saved.

**What changed underneath**

Bundled documentation is now deployed recursively in development builds,
fixing a case where connector docs were missing from the help system during
local testing.
