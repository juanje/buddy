## Pi CLI isolation completed

v0.1.5 isolated skills. Two routes remained open, both because **the SDK resolves a path on its own** when it isn't given one — and neither call looks like a call to a configuration directory.

- Buddy **read the Pi CLI's model definitions** as if they were its own, and cached its own catalogue inside another tool's directory.
- The session **read the Pi CLI's settings**: the user's provider, model, thinking level and theme.

The requirement was restated: passing the right directory where you remember to is not enough — no SDK default may reach the Pi CLI's configuration. Guarded by a test that points at a decoy directory and asserts Buddy never loads it.
