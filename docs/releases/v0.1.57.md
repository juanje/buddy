## Attached images stay attached

An installed copy of Buddy was dropping pictures you attached. The conversation showed a line saying the image could not be resized, instead of the picture. The same build was also refusing, during its own daily maintenance, to read the template it is told to follow when it writes a learned skill, and those refusals were written into the daily log.

**What you could see**

- **An attached image turned into a note that it had been omitted.** Buddy had the file. The installed app was missing the library it uses to shrink images before sending them, so every picture was replaced by that omission line. The library now ships inside the app.
- **Maintenance could not read the skill template.** When Buddy tidies up on its own, it is asked to read a template before creating a learned skill. That read was refused, and the refusal was recorded in the journal. It can read the template now. It still cannot change the template, and it still cannot read credentials.

1,672 unit tests and 768 BDD scenarios pass.
