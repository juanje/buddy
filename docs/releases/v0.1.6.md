## Honest capabilities

No new functionality: this release stops promising what isn't delivered.

- **The OpenAI-compatible provider was withdrawn** — it never worked. The base URL was collected, validated, and then discarded, so the session ended up holding a credential with no address to send it to.
- **The self-documentation said clicking a link could open a file with your default application.** That had been false since v0.1.1. The agent read it and repeated it to users.
- Documented what Buddy does and does not do: which file types it opens and from where, that internal links can be followed, that `fetch_url` cannot reach your own machine, and that Pi CLI skills are not available.
