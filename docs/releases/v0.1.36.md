## New topic button and interactive wrap-up

A "New topic" button now lives in the input bar, between the attach icon and the send button. Clicking it opens a popover with two paths: start a fresh session immediately, or wrap up the current conversation first.

**What you could see**

- **"Start now" switches topics instantly.** The current session shuts down (reflect runs in the background), the chat clears, and a new session boots. Same effect as closing and reopening the app, but without leaving it.
- **"Wrap up first" asks the assistant to close out the conversation before transitioning.** It produces a structured summary — what was discussed, decisions made, open questions, and a suggested next action — then lets you respond, ask follow-ups, or adjust anything. A "Done" button appears inline in the chat; click it when you are ready to move on.
- **The button is disabled while the assistant is responding** and during a topic transition, so it cannot interrupt a stream or fire twice.
- **Labels follow the app language.** Spanish: "Nuevo tema", "Empezar ya", "Rematar primero", "Terminado".

**What changed underneath**

Session transition logic is extracted into a standalone module so the shutdown → dispose → restart sequence is tested without driving the full worker RPC surface. The closure prompt uses the same hidden-message technique as the first-conversation greeting. The "Done" button is a new inline chat component, rendered inside the scroll area so it stays with the conversation as the user types.

1245 unit tests, 448 BDD scenarios. Nothing else should look or behave differently.
