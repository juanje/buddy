## A cleanup and refactoring pass

No new features. A sweep through the codebase for dead code, duplicated logic, documentation that no longer matched the code, and tests that were checking the wrong thing. Almost all of it is invisible from the outside. One setting is gone, because it never did anything.

**What you could see**

- **The "Project prefixes" field is gone from the Jira settings.** It was saved but never read, so no search was ever filtered by it. Buddy recognises issue keys like `PROJ-123` in conversation without it, and the team board is still scoped by the board ID in Settings. The Jira guide no longer promises the old behaviour. If you had prefixes saved, they are ignored and nothing else changes.

**What was one small change away from going wrong**

- **The "where we left off" recap was tested on a copy of its rules.** The app kept its own version of when to ask for the recap, when to show it and when to clear it on a new topic. The tests checked a separate version the app never ran, so a change to the real behaviour would have passed them. The app now uses the tested rules. Nothing about the recap changes.
- **The same happened to the weekly skill-usage counters.** The reset that runs after each weekly consolidation was untested, while an unused copy of it had a test. The test now runs the real reset.
- **The rule that picks a cheaper model for daily and weekly consolidation had no test.** An unused second version of it disagreed at the monthly level: it would have picked the catalogue's recommended model instead of the one you configured. The unused version is gone and the real rule is now tested.

**What changed underneath**

Unused functions, constants, translations and deprecated aliases were removed. Hand-written folder paths were replaced by the named constants that already existed, and two missing dependencies were declared explicitly. Duplicated logic was merged into shared helpers: tool hooks, network-error handling for the Jira and Slack connectors, task helpers, link containment in the file viewer, the Jira and Slack settings panels, and the tasks, Jira and Slack tools themselves. The three largest functions were split into one small handler per action. The developer documentation, methodology guide and specification were brought back in line with the code.

1,460 unit tests and 581 BDD scenarios pass. Apart from the removed Jira field, you should not notice any difference.
