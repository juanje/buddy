## State stops disappearing

The two ways information was lost without anyone noticing.

- **Five state files were written five different ways**, and three treated "cannot read" as "empty" before overwriting: a transient read error was enough to lose every configured provider, or every folder you had authorized. All state now goes through one atomic write that refuses to overwrite what it could not read.
- **Reflect raced the worker for the git index** and the loser lost the whole session summary. Now serialized.
- The background reflect process **had no timeout**: a stalled provider left it running after you closed the app.
