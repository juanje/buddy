## One containment authority, navigation in the viewer

- **The containment rule was implemented four times, and the fourth was wrong.** `relocate_brain_file` checked its prefix with a string comparison that `agent_brain/../.pi/settings.json` satisfies — letting it move the model configuration the system protects. There is now a single authority, and it resolves symlinks.
- **The permission layer read one argument.** `copy_file` and `move_file` name theirs `source`/`destination`, so the denylist that blocks `~/.ssh` and `.env` never applied to them.
- **Links inside an open document now work**, with history to go back. They looked like links and did nothing.
- Sessions no longer inherit the user's Pi CLI setup: globally installed skills, settings and tools from a different application were leaking into every session.
- `~/.buddy/` and its contents are created with restrictive permissions from the outset.
