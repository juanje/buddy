## Jira integration

Buddy can talk to your Jira. Set up credentials in Settings → Integrations
and the assistant gains access to your board, issues, epics, recent changes,
and your team's board — all through natural conversation.

**What you could see**

- **A new Jira panel in Settings.** The Integrations tab lets you enter your
  Jira URL, email, and API token, test the connection, and optionally set
  project prefixes and a team board ID.
- **Nine Jira actions the assistant can use on your behalf.** Personal board
  (active sprint), your open issues, full issue detail with description and
  comments, children of an epic, recent changes, a resolved-issues report for
  any date range, bulk status by issue key, a help summary, and the team board.
- **The team board shows the active sprint, not the entire backlog.** Give it
  your board ID and it returns only what is in the current sprint, with optional
  filters by status or assignee.
- **People queries work by name.** When you say "show me Ozan's issues", the
  assistant resolves the name to a Jira account ID. Names it has seen before
  are resolved locally with no API call.
- **Results are cached and served offline.** If Jira is unreachable, the last
  known data is returned with a staleness warning. Force-refresh is always
  available.
- **Sessions that span a date boundary now correct their own date.** A session
  opened on Friday still knows it is Monday when you come back to it.

**What changed underneath**

Settings is now split into two tabs, General and Integrations. The connector
infrastructure behind Jira — credential storage, cache engine, permission
classification, and conditional tool registration — is designed to be reused
for future services.
