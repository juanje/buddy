## Task hygiene and deferred cleanup

Completed tasks are now cleaned up reliably, the next-action marker recovers automatically when only one task remains, and deferred notifications are removed at session end when the conversation addressed them.

**What you could see**

- **Completed tasks stayed in the list across consolidation cycles.** The cleanup step searched today's log for evidence that a task was really done, flagging unconfirmed ones with a comment that nothing ever processed. Tasks marked done via the `tasks()` tool are now removed unconditionally — the tool call itself is the confirmation.
- **Deferred reminders kept reappearing after being resolved.** If Buddy surfaced a decision or reminder at session start and the conversation addressed it, the item stayed in the queue and came back next session. The reflect now emits resolved items so the worker can remove them before the next boot.
- **A project with one remaining task showed "no next action set".** When the next-action task was completed or removed and only one task remained in the project, nobody marked it as next — the agent was told to suggest one, but often didn't follow through. That sole remaining task is now auto-marked, matching the logic that already existed when adding the first task to a scope.

**What was one small change away from going wrong**

- **The task-file date parser could mistake a frontmatter delimiter for a creation date.** When a tasks.md file had an empty `created:` field (as the template ships), the regex crossed the newline and captured `---` as the date. No real tasks were affected — the `add` action always sets an explicit date — but the edge case broke test helpers and could have corrupted items created through a different path.

**What changed underneath**

WIP (work-in-progress) fronts are now computed from tasks.md instead of parsing the Right now section in AGENTS.md, which eliminates false warnings when Right now bullets lacked area markers. The consolidation prompt references the new source, and Right now's role is clarified in both the consolidation and reflect prompts: it is working memory for situational context, not a task or project list.

1,421 unit tests and 561 BDD scenarios pass. Nothing else is intended to change.
