## Late reflects no longer fall through the cracks

A session that ends after midnight could write its reflect to a log file the
daily consolidation had already processed. That content — decisions, context,
lessons — sat there unread until something happened to draw attention to it.
Buddy now scans for log files updated since the last consolidation and includes
them in the next run automatically.

**What you could see**

- **A late-night reflect was invisible to the next daily.** The consolidation
  prompt only checked today's log and yesterday's. A reflect written at 01:16
  to the day-before-yesterday's log was never picked up — its context, journal
  entry, and Active context updates were silently skipped. The runner now
  compares each log's `last_updated` timestamp against the last consolidation
  and surfaces any with newer content.
- **Log rotation stripped markdown links.** When a log file was archived from
  `logs/` to `logs/archive/YYYY-MM/`, its relative links (to concepts, projects,
  wiki pages) were turned into plain text. They are now rewritten to point to the
  correct depth.
- **The "session expired" card appeared with nothing to do about it.** After a
  boot where the OAuth health check refreshed a stale token successfully,
  Buddy still showed a card telling you to go to Settings — where there was no
  re-login option because the token was already valid. The card now only appears
  when the provider actually needs re-authentication.

**What changed underneath**

New `findPendingLogs` helper compares log frontmatter timestamps against the
consolidation state and injects a "Pending logs" block into the prompt header,
so the LLM reads them before processing today's content.

375 BDD scenarios and 1093 unit tests pass.
